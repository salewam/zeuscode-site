Возможности

Не просто прокси, а слой оптимизации

ZeusCode стоит между вашим кодом и моделями: маршрутизирует, сжимает, страхует и считает деньги.

Умный routing

Запрос уходит в модель, которая лучше подходит под тип задачи, доступность и вашу политику. Для сложных кейсов — reasoning-routing.

Экономия токенов

Дедупликация сообщений, срезание раздутых tool outputs, компактное представление контекста. Меньше входных токенов — дешевле каждый turn.

Комбо-стратегии

Pipeline, fusion и panel: одна модель разбирает задачу, вторая пишет код, третья проверяет. Последовательно или параллельно.

Fallback и retry

4xx, 5xx, timeout или отказ провайдера обрабатываются автоматически. Если основная модель недоступна — выполнение продолжается на совместимой.

Контекст без переполнений

Эффективное сжатие истории у границы окна и зарезервированный headroom, чтобы модели хватило места на полноценный ответ.

Маскирование данных

Чувствительные фрагменты скрываются перед отправкой провайдеру и восстанавливаются в ответе. Ключи и секреты не улетают наружу.

Usage accounting

Видно фактическое потребление, расход по моделям и эффект оптимизации в рублях — а не абстрактные «кредиты».

Стабильность качества

При сжатии сохраняются ключевые инструкции и факты, шум убирается. Ответы не деградируют на длинных сессиях.

Работает в вашем IDE

OpenAI-совместимый формат: Claude Code, Cursor, Cline, Continue, Aider, Zed. Меняете base_url и ключ — и всё.

Как работает

Три шага до первого запроса

1

Получите ключ

Регистрация через Telegram, ключ выдаётся сразу. Стартовый баланс — на тесты, карта не нужна.

2

Подмените base_url

В любом SDK или IDE указываете endpoint ZeusCode. Код менять не нужно — формат OpenAI-совместимый.

3

Кодьте

Указываете модель явно или ставите auto — и routing сам решает, кому отдать задачу.

quickstart.py 
from openai import OpenAI

client = OpenAI(
    base_url="https://api.zeuscode.ru/v1",   # единственное изменение
    api_key="zc-...",
)

r = client.chat.completions.create(
    model="auto",                # routing выберет модель под задачу
    messages=[{"role": "user", "content": "отрефактори этот модуль"}],
    extra_body={
        "zeus": {
            "strategy": "crew",       # architect → builder → finalizer
            "compress_context": True,  # экономия входных токенов
            "fallback": ["claude-sonnet-5", "gpt-5.4"],
        }
    },
)

print(r.choices[0].message.content)
print(r.usage.zeus_saved_tokens)  # сколько токенов сэкономлено
